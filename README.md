# Amazon Automated Reporting Dashboard

## Overview

This project is an interactive **Automated Sales Reporting Dashboard** built using **Microsoft Excel 2019**. It was created as a hands-on practice project to strengthen my skills in **Excel for Data Analysis**, **Dashboard Development**, and **Business Intelligence**.

The dashboard provides an interactive way to analyze Amazon sales data using Pivot Tables, Pivot Charts, Power Query, KPIs, Slicers, and automated data refresh.

This project is part of my learning journey as I continue building practical data analytics projects and improving my Excel skills.


## Features

- Interactive dashboard built entirely in Microsoft Excel
- Category, Month, and Customer Location slicers
- KPI cards displaying:
  - Total Orders
  - Total Revenue
  - Units Sold
  - Gross Sales
- Sales Achievement Gauge
- Orders Achievement Gauge
- Order Status Analysis
- Payment Method Analysis
- Automatic filtering across all visuals
- Pivot Charts with interactive slicers
- Automated data transformation using Power Query
- Refreshable workbook for updated datasets

## Workflow

1. Imported the Amazon sales dataset into Excel.
2. Used **Power Query** to clean and prepare the data.
3. Created Pivot Tables for summarizing sales information.
4. Built Pivot Charts for data visualization.
5. Added interactive slicers for filtering.
6. Designed KPI cards using Pivot Table values and Sparklines.
7. Created achievement gauges using Doughnut Charts.
8. Connected all dashboard elements for an interactive reporting experience.

## Automated Reporting

The workbook demonstrates a basic automated reporting workflow.

Using **Power Query**, the dashboard can be refreshed whenever the source dataset is updated.
